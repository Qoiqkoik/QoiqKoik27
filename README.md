# QoiqKoik27

-Deskripsi File
1. index.html
   merupakan file utama yang digunakan untuk membangun struktur dan isi dari website biodata. File ini mengatur berbagai bagian yang ditampilkan pada website, seperti Home, Tentang Saya, Pendidikan, Skills, Hobi, Portfolio, dan Kontak. Selain itu, file index.html juga digunakan untuk menampilkan foto profil dan menghubungkan file CSS serta JavaScript agar website dapat memiliki tampilan dan interaksi yang sesuai.
2. style.css
   merupakan file yang digunakan untuk mengatur tampilan website. File ini mengatur berbagai aspek visual seperti warna, ukuran, posisi elemen, jenis tulisan, jarak antar bagian, tampilan foto profil, serta layout website. style.css juga digunakan untuk membuat website menjadi responsive sehingga tampilannya dapat menyesuaikan dengan ukuran layar desktop, tablet, maupun perangkat mobile.
3. script.js
    merupakan file JavaScript yang digunakan untuk memberikan fungsi interaktif pada website. Pada website ini, JavaScript digunakan untuk menerapkan manipulasi DOM, salah satunya melalui tombol “Ubah Teks” yang dapat mengubah isi teks pada halaman ketika tombol ditekan. Dengan adanya JavaScript, website tidak hanya menampilkan informasi secara statis tetapi juga memiliki interaksi dengan pengguna.
4. assets/JahrulQoiqAssyafi.jpg
   merupakan file gambar yang digunakan sebagai foto profil pada website. Folder assets digunakan untuk menyimpan file pendukung website, sedangkan JahrulQoiqAssyafi.jpg merupakan foto profil yang ditampilkan pada bagian Home. File gambar tersebut dipanggil melalui index.html sehingga dapat ditampilkan pada halaman website.

-Kesimpulan
Website biodata ini dibuat menggunakan HTML, CSS, dan JavaScript sebagai penerapan dasar dalam pengembangan website. HTML digunakan untuk membuat struktur dan menyusun informasi biodata, CSS digunakan untuk mengatur tampilan serta membuat website responsive, sedangkan JavaScript digunakan untuk memberikan interaksi melalui fitur DOM. Website ini juga dilengkapi dengan foto profil dan beberapa informasi mengenai pendidikan, kemampuan, hobi, portfolio, serta kontak. Dengan dibuatnya website ini, diharapkan dapat meningkatkan pemahaman dalam mengembangkan website sederhana menggunakan HTML, CSS, dan JavaScript serta menerapkan hasil pembelajaran ke dalam sebuah project yang dapat diakses melalui browser.
